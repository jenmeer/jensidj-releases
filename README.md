# jensiDJ – Downloads

Installationsdateien von **jensiDJ** (DJ-Software für macOS und Windows).

- **Neueste Version:** unter [Releases](../../releases/latest)
  - Mac (Apple Silicon): `jensiDJ-…-mac.dmg` öffnen, `jensiDJ.app` in „Programme“ ziehen, beim ersten Start Rechtsklick → „Öffnen“
  - Windows 11 (x64): `jensiDJ-…-windows-setup.exe` starten (bei SmartScreen „Weitere Informationen“ → „Trotzdem ausführen“)
- jensiDJ sucht beim Start selbst nach neuen Versionen und fragt vor dem Installieren.
- `controllers/`: Controller-Profile, die jensiDJ automatisch nachlädt.

Dieses Repository enthält nur Downloads, keinen Quellcode.
